# Everyday Pantry: one project, four stages

Frontend Foundry teaches the same small product repeatedly instead of switching projects whenever a new language appears.

## Open in order

1. [01 HTML Pantry](01-html-pantry/index.html) builds meaning and structure only.
2. [02 CSS Pantry](02-css-pantry/index.html) keeps the markup and adds a design system, layout, responsive rules, and focus states.
3. [03 Tailwind Pantry](03-tailwind-pantry/index.html) keeps the product and translates the CSS decisions into utility classes. The source includes comments naming each utility family and links to the [Flowbite Tailwind Cheat Sheet](https://flowbite.com/tools/tailwind-cheat-sheet/).
4. [04 JavaScript Pantry](04-javascript-pantry/index.html) keeps the Tailwind interface and adds data, events, filtering, rendering, and local storage.

## Learning rule

At every stage, compare the folder with the previous folder. Ask what stayed the same, what new responsibility was added, and which lines of code now own that responsibility. The product is not being replaced; it is being improved.
