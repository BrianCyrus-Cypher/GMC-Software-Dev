# 01 / HTML foundations

## The daily-life problem

A weekly meal planner needs headings, groups of meals, actions, and a clear reading order. HTML is the layer that describes those relationships.

## Inspect the dashboard

Find `header`, `nav`, `main`, `section`, `article`, `form`, `label`, and `footer` in `index.html`. These elements tell a browser, screen reader, and future developer what each part is for.

## Practice

1. Add a new lesson card for `06 / Ship it`.
2. Give it a heading, a useful description, and a button.
3. Add a new field to the measurement form with a matching `label` and `id`.
4. Use the browser inspector to check the structure before adding styles.

## Checkpoint

Can somebody understand the page outline by reading only the headings and landmarks? If not, improve the HTML before touching color or spacing.
